噪声与 FBM：程序化云层 hash 生成随机，value noise 做平滑，FBM 把多层细节叠起来

规则图案看多了会腻。自然界的云、雾、岩石都有「随机但有结构」的纹理，噪声函数就是 shader 里生成这种纹理的万能工具。

  • 用 hash 把坐标映射成伪随机值
  • 用双线性插值把随机点变成平滑噪声

01从 hash 开始

真正的随机数在 shader 里成本高且不可复现；我们只需要「同样的坐标永远得到同样的随机值」。一个常见的 hash 是把坐标做 sin/点乘/fract 组合：

float hash(vec2 p) {
  p = fract(p * vec2(123.34, 345.45));
  p += dot(p, p + 34.345);
  return fract(p.x * p.y);
}

hash 输出的值在格子之间是跳变的，直接用会像电视雪花。下一步是在格子之间做平滑插值，这就是 value noise。

02value noise 与 FBM

在整数格点上取 hash，再对四个角做 smoothstep 插值。单层噪声已经有点云的感觉，但缺少细节；FBM 把噪声按频率翻倍、振幅减半地叠加：

float noise(vec2 p) {
  vec2 i = floor(p), f = fract(p);
  f = f * f * (3.0 - 2.0 * f);
  float a = hash(i);
  float b = hash(i + vec2(1.0, 0.0));
  float c = hash(i + vec2(0.0, 1.0));
  float d = hash(i + vec2(1.0, 1.0));
  return mix(mix(a, b, f.x), mix(c, d, f.x), f.y);
}

float fbm(vec2 p) {
  float v = 0.0, a = 0.5;
  for (int i = 0; i < 5; i++) {
    v += a * noise(p);
    p *= 2.03;
    a *= 0.5;
  }
  return v;
}
像用不同粗细的笔刷叠画

第一层是大笔刷，决定云的大块形状；第二层细一点，补边缘；第三层更细，补毛刺。振幅逐层减半，避免细节盖过整体。

类比到哪为止：画画可以随时收笔；shader 里的层数是固定的，层数越多越贵，需要按性能取舍。

03上色

把 fbm 的输出当作密度：低密度给深色，高密度给亮色，再用 smoothstep 做柔和过渡。颜色不要直接用 RGB 随机，而是取一个有限色板，画面会更统一。

float f = fbm(vUv * 3.2 + vec2(uTime * 0.03, uTime * 0.02));
vec3 col = mix(vec3(0.02,0.03,0.08),
               vec3(0.12,0.55,0.60),
               smoothstep(0.35, 0.7, f));
col += vec3(0.7,0.3,0.8) * smoothstep(0.55, 0.82, f) * 0.45;
🔬 深入：value noise 和 simplex noise 差在哪？

value noise 在格点上取随机值再插值，计算便宜，但容易看出网格方向；simplex/perlin noise 在梯度上插值，方向性更弱、观感更自然，但实现更复杂。FBM 对两者都适用。

移动端预算紧时，value noise 往往是更实际的选择；需要更「有机」的形状时，再换 simplex。

04自测

hash 的作用是什么？

把坐标映射成固定但看起来随机的值；同样的输入永远得到同样的输出，所以动画可复现、无需存储随机表。

为什么 FBM 每层要乘 2.03 而不是 2.0？

避免频率正好成整数倍导致重复图案；稍微错开可以掩盖周期性。振幅同时减半，保证细节不会压过整体。

FBM 层数越多，画面越好吗？

不一定。层数增加提升细节，但也线性增加开销；很多场景 4–6 层已经足够，剩下的交给颜色和构图。

这一讲带走

hash 产生随机，noise 把随机变平滑，FBM 把平滑叠出细节。三者组合是云、雾、地形、水面等所有自然纹理的起点。
