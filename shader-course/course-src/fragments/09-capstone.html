01场景就是多个 SDF 的并集

球体与圆环分别是一个距离函数，取 min 就得到「离任一物体最近」的距离。raymarch 不需要知道场景里有几个物体，它只需要一个 map(p)。

float map(vec3 p) {
  vec3 q = p;
  q.xz = rot(uTime * 0.18) * q.xz;
  float sphere = length(q) - 0.75;
  float torus = length(vec2(length(q.xz) - 1.35, q.y)) - 0.28;
  return min(sphere, torus);
}

圆环 SDF 的写法值得记住：先算 xz 平面到圆心的距离，再与 y 组成二维向量，减去管半径。这样圆环会绕 y 轴旋转，而不是平躺在屏幕上。

02给画面收尾

材质色、背景渐变、雾、暗角，这些「收尾」决定了画面是否像一件完整作品。一个简单的背景渐变就能让黑底上的几何体立刻有空间感。

vec3 col = vec3(0.015, 0.03, 0.08);
if (t < 9.0) {
  vec3 n = calcNormal(p);
  float diff = max(dot(n, normalize(vec3(0.5,0.9,0.3))), 0.0);
  float rim = pow(1.0 - max(dot(n, -rd), 0.0), 2.5);
  col = vec3(0.1,0.8,0.7) * diff
      + vec3(0.9,0.35,0.9) * rim * 0.8;
}
col += vec3(0.3,0.15,0.5) * smoothstep(0.8, 0.0, length(uv));
像搭一组静物摄影

几何体是摆件，光照是灯，背景是幕布，雾和暗角是镜头氛围。每件东西都简单，组合起来才成为一张照片。

类比到哪为止：摄影受物理约束；shader 里你可以随意让球和环互相穿插，只要距离函数写得出来。

03结课项目建议

  1. 换材质：给球和环不同颜色，或按法线方向混色。
  2. 加噪声：用 fbm 扰动 SDF 表面，做出岩石/液态金属质感。
  3. 加交互：鼠标控制旋转速度或相机位置，滚轮改变 fog 密度。
  4. 加后处理：把场景颜色做暗角、色调映射或扫描线，形成自己的风格。

三条常见路线：图形学（光照模型、PBR、阴影、后处理）、程序化艺术（噪声、SDF、生成式构图）、工程化（WebGL2、Three.js ShaderMaterial、性能与多 pass）。

别急着学框架。先用原生 WebGL 把「一个全屏 shader + 一个 SDF 场景」写熟，再换框架会发现只是换了 API，核心概念没变。

04自测

两个 SDF 用 min 组合，表示什么？

表示两个形状的并集：空间中任意点到「最近的任一表面」的距离。raymarch 用这个距离安全前进。

圆环 SDF 里为什么要先算 length(q.xz)？

圆环可以看成「xz 平面上到圆心距离为 R 的圆」与「y 方向上的管截面」的组合；先算平面距离，再与 y 组成二维向量，才能得到正确的管状距离。

如果场景中有 3 个物体，map 应该返回什么？

返回三个 SDF 的最小值（或 smooth min）。raymarch 只关心最近表面距离，不关心物体数量。
