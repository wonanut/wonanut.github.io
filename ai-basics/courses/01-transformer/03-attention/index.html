注意力机制

Q、K、V 如何让模型学会「关注」

💡

为什么

看这句话：

「猫追老鼠，因为它饿了。」

「它」指谁？人类会不假思索地答「猫」。因为我们会自动把「它」和前面最相关的词连起来。

注意力机制（attention）就是让模型学会这件事：在理解某个 token 时，决定该「看」哪些 token、各看多重。

✨

用一个「查字典」的类比来理解三个角色：

  • Query（查询）：你现在想搞清楚的那个词，比如「它」；
  • Key（键）：字典里每个词的「索引标签」；
  • Value（值）：每个词真正携带的「内容」。

注意力做的事，就是拿 Query 去和每个 Key 比相似度，决定「这个词该分多少注意力给每个位置」，再把对应的 Value 按权重拿回来。

🖼️

可视化

下面这张热力图就是注意力的可视化。每一行是一个「查询」位置（它想看谁），每一列是「被看」的位置，颜色越深关注越重。每一行的权重加起来等于 1（是概率分布）。

✨

悬停任意格子，会显示「谁在看谁、权重多少」。观察两件事：

  1. 对角线偏重：每个词都会「先关注自己」；
  2. 有选择地分权重：「爱」主要关注自己，也分一点注意力给「我」和「学习」。

这正是注意力的妙处——不是全看，也不是只看自己，而是按相关性分配。

🧮

形式化

每个 token 先生成三个向量（各由一个可学习矩阵投影，矩阵是训练出来的）：

Q=xWQ,K=xWK,V=xWVQ = x W^Q,\quad K = x W^K,\quad V = x W^VQ=xWQ,K=xWK,V=xWV

然后三步计算注意力：

  1. 求相似度：QQQ 和每个 KKK 做点积，得到「这个位置和每个位置多相关」的原始分数；
  2. 缩放 + softmax：除以 dk\sqrt{d_k}dk​​ 防止分数过大，再 softmax 变成和为 1 的权重；
  3. 加权求和：用这些权重对 VVV 加权求和，得到这个位置的输出。
Attention(Q,K,V)=softmax ⁣(QK⊤dk)V\text{Attention}(Q,K,V) = \text{softmax}\!\left(\frac{QK^\top}{\sqrt{d_k}}\right) VAttention(Q,K,V)=softmax(dk​​QK⊤​)V
💡

  3. softmax 后得权重约 [0.42, 0.21, 0.36][0.42,\ 0.21,\ 0.36][0.42, 0.21, 0.36]；
  4. 用这三个权重对 V1,V2,V3V_1,V_2,V_3V1​,V2​,V3​ 加权求和，得到位置 1 的输出。

动手

softmax 是注意力的「灵魂」——它把任意分数变成概率分布。拖动下面的 temperature，观察权重分布如何被「软化」（更平均）或「锐化」（更集中）。

logit[0]2.0
0.705
logit[1]1.0
0.259
logit[2]-1.0
0.035

softmax 把 logits 变成概率分布；temperature 越大分布越平缓。

⚠️

temperature 是「采样」时的概念（下一门课会细讲），这里借它来感受 softmax 的陡峭程度。注意力训练时一般 temperature = 1，不额外调节。

要点回顾

  • 注意力 = 每个位置用 QQQ 去和所有 KKK 比相似度，softmax 成权重，再对 VVV 加权求和。
  • 三个角色：Query（找什么）、Key（提供什么）、Value（取出什么）。
  • 缩放 dk\sqrt{d_k}dk​​ 是为了训练稳定；softmax 保证权重是概率分布。
