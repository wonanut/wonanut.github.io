L0第 3 课

怎么用这套课

五步模板、交互分级与十门课的入口

💡

为什么

这是一套交互式课程，不是文档合集。

每节课都按同一个五步模板组织，目的是让你在一节 10–15 分钟的时间里走完一个完整的小循环：先建立直觉，再形式化，再动手，最后自测。知道模板怎么用，能显著提高吸收效率——比如「可视化」区块不是配图，而是让你先产生预测，再去验证。

🖼️

可视化

五步模板各自解决什么：

💡
  1. 💡 为什么：30 秒说清这个知识点解决什么问题。先建立动机。
  2. 🖼️ 可视化：交互图或动画。先玩，先形成直觉，不急着看公式。
  3. 🧮 形式化：轻量数学与精确定义，只到「够用」。看到公式时回想刚才的可视化。
  4. 🛠️ 动手：playground 或真机命令。亲手改参数、跑一遍，比读十遍有效。
  5. 🎯 检查点：即时反馈的小测验 + 要点回顾。答错不要紧，回到对应区块再看一遍。

交互性分四级，用来标注每节课的「动手强度」：

💡
  • L0：静态图（SVG / 文本图），用来建立结构直觉。
  • L1：可交互可视化（hover / 拖拽 / 逐步），用来观察变量之间的关系。
  • L2：浏览器内 playground（纯前端逻辑），用来亲手跑算法。
  • L3：真机上手 + 会话 trace 回放。工具课用它替代「在浏览器里跑真实 CLI」。

课程页顶部会标出等级。L3 不代表更难，只代表「需要你本地动手或看真实轨迹」。

🧮

形式化

把学习过程写成一个循环：

预测→动手验证→修正直觉→再预测\text{预测} \rightarrow \text{动手验证} \rightarrow \text{修正直觉} \rightarrow \text{再预测}预测→动手验证→修正直觉→再预测

具体建议：

✨
  • 先猜后看：打开可视化之前，先猜「拖动 temperature 会让分布变尖还是变平」，再去拖。预测错误带来的修正最强。
  • 一节课一个产出：一条能复述的笔记、一个 playground 参数结论、或一段能运行的命令。
  • 间隔复习：学完一门课，隔一天再回来看「要点回顾」，只花 2 分钟。
  • 面试导向：每节的「要点回顾」基本就是可复述的答案骨架。

不建议的做法：只读「形式化」跳过动手；或者只看可视化不记定义。直觉和定义要成对出现。

🛠️

  • 07 Hermes 自进化 —— 自进化 harness + 终局对比

建议的第一次练习：任选一门课，打开它的第一个可视化，先写下你的预测，再交互，最后用一句话记录「我猜错了什么」。这个动作只要 3 分钟，但会让后面的学习完全不同。

⚠️

这套课是纯前端静态站点：没有账号、没有进度同步、也不会在浏览器里运行真实 CLI。工具课的真机部分需要你在本地终端完成；站内提供的是可复制的命令块、预录 trace 和逐步模拟器。
