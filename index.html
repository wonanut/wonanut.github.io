About · 关于

一个想把东西做扎实的人

我是 Doran（网名 wonanut），西安交通大学研究生。对「模型能把事情做到什么程度」和「工程如何让这件事稳定发生」同样着迷。

这些年写过后端、前端、数据可视化，也做过游戏原型：从 Spring Boot 的旅游网站，到 Canvas 复刻的动态磁贴，再到实验室里的 TCR–表位结合预测。跨度看起来大，底层兴趣其实是一个——把复杂系统拆开，再重新拼成好用的东西。

现在把主要精力放在 Agent Harness 工程：工具怎么写、权限怎么划、上下文怎么管、任务怎么跨会话存活、多个 Agent 怎么协作。这门《Claude Code 内功课》，就是我整理这套理解的方式——先自己讲明白，再讲给别人听。

长期想做的事：做一款自己的独立游戏。在那之前，先把工程底子打厚。

— Doran · 西安
