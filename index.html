About · 关于

一条越走越宽的工程线索

我是 Doran（网名 wonanut）。2018 年本科毕业于西安交通大学计算机科学与技术专业，2021 年硕士毕业于同校计算机技术专业，之后一直在华为做技术研究，现在在上海。

研究方向横跨四块：交互体验、企业海量数据治理、知识图谱落地、Agent 技术企业落地。看起来跨度大，底层其实是一条线索——让复杂系统真正被人和业务用起来：先理解人怎么用（交互），再让数据可信（治理），再让知识连起来（图谱），最后让智能去执行（Agent）。

企业场景教会我的事很朴素：demo 能跑不等于能交付。权限、边界、评测、可观测、失败恢复——这些不性感的部分，决定了技术能不能被真正用起来。这也是我写《Claude Code 内功课》的原因：把 Agent 的工程细节讲清楚，而不是只讲它能做什么。

工作之外，我写代码、做小游戏原型、整理笔记。长期想做的仍然是那件事：做一款自己的独立游戏。在那之前，先把工程底子打厚。

— Doran
